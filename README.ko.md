# 토치라이트 오버레이 KO 1.0.1

타르타로스와 블러드 러스트 수술 준비를 돕는 Windows x64용 비공식 추천 오버레이입니다.

1. ZIP 전체를 쓰기 가능한 폴더에 풀고 `TorchlightHelper.exe`를 실행합니다. .NET은 포함되어 있습니다.
2. 기존 TartarusSolver를 종료합니다. 같은 단축키를 사용하는 다른 오버레이와 동시에 실행하지 마세요.
3. 게임 언어를 한국어 또는 English로 선택합니다.
4. `콘텐츠 자동 감지`를 켜둡니다. 콘텐츠에 입장하면 자동으로 전환되며 탭을 바꿀 필요가 없습니다. 감지된 엔진만 실행합니다.
5. 블러드 러스트에서는 인턴 의사 세라일의 미보유 또는 1~6단계를 선택합니다. 설정은 자동 저장됩니다.

게임은 창 모드 또는 테두리 없는 창 모드를 사용합니다. 자동 인식에는 게임의 계정 관련 설정에서 로그를 활성화하고 재접속해야 합니다. 로그를 찾지 못하면 `로그 선택`으로 `UE_game/Torchlight/Saved/Logs/UE_game.log`를 지정하세요.

자동 모드의 탭은 설정 보기용입니다. `콘텐츠 자동 감지`를 끄면 탭으로 직접 엔진을 선택할 수 있습니다. 로그를 읽지 못하면 자동 전환은 대기합니다.

## 추천 표시

- 타르타로스: 초록색 굵은 테두리가 추천 선택지입니다. 상자 아이콘 옆 숫자는 예상 완주 보상입니다.
- 블러드 러스트: 카드 번호와 대상 탱크 번호, 밝은 테두리를 확인합니다. 선택과 확인은 직접 진행합니다.
- 84만 달성률은 현재 인식한 상태, 모델과 확률표로 계산한 추정입니다. 수술 플랜의 보너스와 사망 위험에 따라 실제 보상이 달라집니다.
- 펫 단계는 화면에 보이지 않는 도구 새로고침 횟수의 초기값입니다. 화면에서 확실히 읽은 실제 남은 횟수가 우선합니다.
- 수술 플랜(11~13라운드)은 캐릭터의 생존력과 전투 조건에 따라 선택해야 하므로 자동으로 특정 카드를 최선이라고 표시하지 않습니다.
- 읽지 못한 카드나 수치가 있으면 추천을 숨기고 `인식 확인 필요`를 표시합니다. 카드를 가린 창이나 툴팁을 치우고 다시 인식하세요.

## 성능과 데이터

블러드 러스트는 선택지당 256/512/1,024회 탐색을 지원합니다. 기본은 정밀 1,024회이며 계산 스레드는 CPU 논리 코어의 절반, 최대 8개입니다. CPU 사용 설정에서 게임 우선(최대 4개), 균형(최대 8개), 추천 속도 우선(최대 12개)을 선택할 수 있습니다. 게임 프레임이 떨어지면 균형이나 빠르게를 선택하세요. 타르타로스의 인식 간격과 탐색 품질은 별도로 조절합니다.

게임 메모리를 읽거나 바꾸지 않으며, 게임에 클릭이나 키 입력을 보내지 않습니다. 캡처와 로그를 로컬에서 처리합니다. 자동 업데이트, 통계 전송, 오류 자동 전송은 이 배포본에서 사용하지 않습니다. 설정과 로컬 기록은 실행 파일 옆 `user-data`에 저장합니다.

타르타로스 한국어 OCR 모델은 포함되어 있습니다. 블러드 러스트는 Windows 한국어 OCR이 있으면 카드명 인식에 사용하며, 없으면 이미지 인식으로 보완합니다. 한국어 카드명 78개를 연결했고, 미확인 7개 명칭은 영어로 표시됩니다. 일부 특수 포션 연속 효과는 지원 범위가 제한됩니다. 모든 패치, 해상도, UI 배율에서 인식을 보장하지 않습니다. Vorax 확률표 기준일은 2026-10-22이며, 타르타로스는 v0.7.20에 포함된 모델을 사용합니다.

## 배포

다른 사람에게는 제공된 ZIP을 공유하세요. 사용 중인 폴더를 다시 압축할 때는 `user-data`, 로그, 진단 이미지와 개인 설정을 제외해야 합니다. `licenses`와 `THIRD_PARTY_NOTICES.md`를 함께 유지하세요. 게임명과 게임 자산은 권리자에게 귀속되며, 게임 제작사의 공식 도구가 아닙니다.

## 소스 빌드

`tartarus/`는 glcoder/TartarusSolver v0.7.20의 MIT 소스, `vorax/`는 DinoRaos/vorax-solver-rs 9aabc20의 MIT 소스를 기반으로 합니다. 두 저작권 고지를 보존합니다. 제한적 라이선스로 변경된 다른 솔버의 최신 코드는 포함하지 않습니다.

`build.ps1`은 .NET SDK와 로컬 Rust GNU 툴체인으로 독립 실행형 배포 폴더를 만듭니다. `package.py`는 허용된 파일만 ZIP에 담고 SHA-256과 포함 목록을 생성합니다. 공개 업로드는 별도입니다.
