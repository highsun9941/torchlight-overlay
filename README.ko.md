# Torchlight Helper 1.2.7

[실행 방법, 최대 성능 모드, 진단과 빌드 안내는 README.md에 있습니다.](README.md)

[실행용 ZIP 다운로드](https://github.com/highsun9941/torchlight-overlay/releases/latest)

같은 선택 화면에서는 이미 확인한 정보를 유지하고 미확인 카드 한 장씩만 안내합니다. 실제 라운드·보드·선택지가 바뀌면 임시 기억을 갱신합니다.

인식 실패 시 라운드·탱크·카드·새로고침 중 실패한 항목을 표시하고 해당 위치를 파란색으로 안내합니다. 새로고침 횟수는 보정 전 원본 영역으로도 검증하며 숫자가 없으면 0회로 확정하지 않습니다.

같은 그림의 포션 변형은 독충/경비병 등 종류 글자를 확인해야 확정합니다. 선택 화면의 텍스트 위치를 고정해 비교하며, 읽을 수 있는 카드의 그림·배경 및 탱크 내부 애니메이션 변화는 재인식 사유로 삼지 않습니다.

금색 수술 도구의 확대 테두리와 제목 대비를 별도로 처리하며, 짧은 제목의 한 음절 손상은 원본/확대 그림과 전체 목록의 유일성을 검증한 경우에만 복구합니다.
